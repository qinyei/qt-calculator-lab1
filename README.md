# 实验1 · 带键盘事件的计算器

《Qt 应用程序开发》实验一 —— 一个能用鼠标也能用键盘操作的四则运算计算器。

## 功能

- 四则运算：加、减、乘、除
- 小数输入、正负号、百分号
- 一元运算：倒数 `1/x`、平方 `x²`、开平方 `√x`
- 编辑：退格 `⌫`、清除当前输入 `CE`、全部清除 `C`
- **键盘输入**：数字、`. + - * /`、回车（=）、退格、Esc（C）、Delete（CE）、`%`

## 求值模型：整式求值（带运算优先级）

计算器有两种常见做法，本程序采用后者：

| 模型 | 典型代表 | `2 + 3 × 4 =` |
|---|---|---|
| 即时运算 | Windows 标准计算器 | 按 `×` 时就先算出 5，结果是 **20** |
| **整式求值（本程序）** | 手机计算器 / 科学计算器 | 攒成整条算式后一次求值，先乘除后加减，结果是 **14** |

具体表现：

- 输入过程中，显示区**实时显示整条算式**（如 `2+3×4`），不会提前出中间结果；
- 按 `=` 时一次性求值，遵守**先 × ÷、后 + −，同级从左到右**；
- 按 `=` 之后，上方小字保留刚才那条算式（`2+3×4 =`），显示区给出结果；
- 结果可以继续参与下一条算式（`2+3=` 之后按 `+4=` 得 9）；直接输入数字则开始一条新算式。

## 工程结构

| 文件 | 作用 |
|---|---|
| `calculator.h` / `calculator.cpp` | **计算核心**：状态机与输入规则，与界面完全解耦 |
| `mainwindow.h` / `mainwindow.cpp` | 主窗口：把按钮点击与键盘按键导到同一个入口 `handleKey()` |
| `mainwindow.ui` | Qt Designer 界面（显示区 + 4×6 按钮网格） |
| `main.cpp` | 程序入口 |

## 设计要点

1. **鼠标与键盘复用同一套逻辑** —— 按钮的 `clicked` 与键盘的 `keyPressEvent` 都调用
   `MainWindow::handleKey()`，再转交 `Calculator::enter()`；不存在两份运算代码。
2. **逻辑与界面分离** —— 所有状态（第一个操作数、待执行运算符、当前输入、是否新输入）
   都封装在 `Calculator` 里，可脱离 GUI 单独测试。
3. **异常输入**：连续小数点、连续运算符、除数为 0、负数开平方等都有明确处理。

## 构建与测试

用 Qt Creator 打开 `calculator.pro` 直接构建；或命令行：

```bash
mkdir build && cd build
qmake .. && mingw32-make -j4
./release/calculator.exe
```

核心逻辑可以脱离界面单独测试（`tests/` 目录，共 62 项断言）：

```bash
cd tests && mkdir build && cd build
qmake ../test_calculator.pro && mingw32-make -j4
./release/test_calculator.exe
```

测试覆盖：运算优先级、四则运算、浮点噪音、连续小数点、连续运算符、
除数为 0（末位与算式中途）、算完后继续输入、输入过程中退格、退格退到空、
清除/CE、正负号、一元运算、输入位数上限。
